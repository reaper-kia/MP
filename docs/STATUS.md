# Статус: что работает, что имитация, чего нет

Таблица для README, защиты и ответов на вопросы (критерий «Выступление и ответы»). Правило:
**«работает» пишем, только если сами запустили и видели результат**. Остальное — «проверено
тестами», «имитация» или «нет».

Обозначения: ✔ проверено запуском · ◐ проверено тестами / частично · ⌛ ждёт доступа · ✘ нет.

## Известные ограничения

- **Поиск по всей площадке VK / OK** недоступен: VK закрыл `newsfeed.search` для ключей приложений
  (1051), у OK и MAX открытого поиска нет, Yandex Search API платный и не подключён. «Везде» — все
  активные источники каталога края + RSS-ленты сайтов.
- **MAX** не подключён на стенде: токен бота выдают только юрлицу или ИП. Код готов; агентству
  достаточно выдать токен (`MAX_BOT_TOKEN`).
- **Модели на стенде** берутся с ноутбука команды; ноутбук недоступен — эвристики с
  предупреждением «ML работал в упрощённом режиме».
- **Скорость:** поиск по ~15 источникам с моделями — 1–5 минут; поиски идут по одному (очередь),
  повтор того же поиска — из кэша.
- **Качество отбора** измерено только на придуманных текстах; на реальных постах — ручная проверка
  в прогонах, без метрик.
- RSS сайтов — только свежие материалы (1–3 дня). Сюжеты собираются кусками по 500 постов.
