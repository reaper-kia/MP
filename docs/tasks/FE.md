# FE — фронтенд (веб + расширение)

Зона: `frontend/**`, `extension/**`. Контракт: **`contracts/http/openapi.yaml`** — пишешь только по нему.
С первой минуты работаешь на моках, бэкенд не ждёшь. UX — это 15 баллов (5 сценариев по 2 + общий
UX/UI 5) + 5 баллов «Демонстрация». Пользователь — сотрудник агентства **без технической подготовки**.

Стек: React 19 + Vite + TS (уже в шаблоне). Рекомендую добавить:
- `react-router` — `/` (поиск), `/search/:id` (подборка), `/sources`;
- `@tanstack/react-query` — опрос статуса, кэш, ретраи;
- UI-кит **Mantine** (таблицы, date range picker с ru-локалью, модалки, уведомления) — быстро и ровно;
- `openapi-typescript` + `openapi-fetch` — типы прямо из `openapi.yaml`;
- `msw` — «живые» моки сценариев.

Логин из шаблона (`AuthPage`) убрать — по ТЗ регистрация не нужна, все ручки анонимные.

### [ ] FE-01 · P0 · к H+2 · база и моки
1. `npx openapi-typescript ../contracts/http/openapi.yaml -o src/api/schema.d.ts`, клиент на `openapi-fetch`

2. Prism: `npx @stoplight/prism-cli@5 mock ../contracts/http/openapi.yaml -p 4010`, в `vite.config.ts`
   proxy `/api` → `VITE_API_TARGET` (по умолчанию `http://localhost:4010`, потом `:8000`).
3. Каркас: роутинг, layout (шапка: «Поиск» · «Источники» · «История»), тема Mantine, `dayjs` ru + tz
   `Asia/Krasnoyarsk` для показа дат.

**DoD.** Список источников с Prism отображается.

### [ ] FE-02 · P0 · к H+4 · MSW: живые сценарии
Prism статичен, а поиск живёт во времени. `src/mocks/` (включается `VITE_MOCKS=1`):
- `POST /searches` → id; `GET /searches/:id` проходит `queued → analyzing_query → collecting`
  (цели переходят pending → running → done/empty/failed по таймеру) `→ scoring → done`;
- набор по ТЗ: запрос с «безопасность» → `partial` (OK упал с TIMEOUT), 25 результатов с группами,
  1 без даты, 3 спорных, вкладка «отсеяно»; текст новости → 3 размещения одного сюжета; запрос
  «пусто» → `completed` с 0; запрос «ошибка» → `failed`;
- `retry` поднимает упавшую цель; `exclusion` пересчитывает `counts`; `export` отдаёт любой файл.

**DoD.** Все 5 сценариев ТЗ проходятся в UI на моках.

### [ ] FE-06 · P0 · к H+12 · состояния (сценарий 5)
Три **разных** вида, не путать:
- **Ничего не найдено** (`completed`, `total=0`): нейтральная иллюстрация, «Подходящие публикации не
  найдены» + где искали (N источников, площадки, период) + советы (расширить период, режим «Везде»).
- **Частично** (`partial`): подборка как обычно + жёлтый баннер «Не удалось обработать 2 источника» +
  «Повторить».
- **Ошибка** (`failed` или сеть): красный блок с текстом и «Повторить»; уже найденное (если было) не
  исчезает.
Единые цвета статусов во всём приложении (done — зелёный, empty — серый, failed — красный,
running — синий).

### [ ] FE-10 · P1 · к H+30 · расширение Chrome (MV3)
`extension/`: `manifest.json` (MV3, `side_panel.default_path`, `permissions: ["sidePanel","activeTab"]`,
`host_permissions` на адрес сервера), сборка того же приложения в side panel (`vite build --mode
extension`, `base: './'`, `VITE_API_URL=http://<сервер>`), клик по иконке открывает панель.
Фича расширения: **«Добавить эту страницу в источники»** — берёт URL активной вкладки → `resolve` →
предпросмотр → добавить. Скрипт `npm run build:ext` → `extension/dist`. Инструкция установки для README
(режим разработчика → «Загрузить распакованное», без прав администратора).
