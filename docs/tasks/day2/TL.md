**Сделать.**

   `YC_SEARCH_API_KEY`, роль `search-api.webSearch.user`.

3. Заодно (для ML-11): API-ключ того же аккаунта с ролью `ai.languageModels.user` (YandexGPT и
   эмбеддинги) → `YC_API_KEY` в `.env`. Точный набор ролей сверить с документацией Foundation Models.
4. `docker compose restart collector_service`, поиск «Везде» по VK + OK на «ДТП Красноярск» за 7 дней.

**DoD.** Поиск «Везде» завершается `completed` или `partial` без 403 у VK и OK; в «Где искали»

### [ ] TL-16 · P0 · вместе с B1-11 · MAX_BOT_TOKEN в окружение
**Цель.** MAX в Docker сейчас всегда «недоступна»: переменная `MAX_BOT_TOKEN` есть в настройках
сборщика, но не передаётся ни в `compose.yaml`, ни в `env.j2`, ни в `.env.example`. Площадки 3 → 5 баллов.

`DEPLOY_KEYS` в `Makefile`.

**DoD.** С токеном в `.env` `/api/v1/platforms` показывает MAX не `unavailable`; на сервере после
`make deploy` — то же.
