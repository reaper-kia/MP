# FE-17 · Расширение браузера «Проверить пост»

**Исполнитель:** один человек (FE). **Приоритет:** P1 (даёт баллы «Пригодность», «Доп. идеи»,
«Тех. доп. возможности»; ТЗ: «предпочтительно расширение»). **Оценка:** 5–7 часов.

## Сценарий

Сотрудник листает VK (или любой сайт), видит сомнительный пост и хочет проверить, где ещё это
публиковали, не открывая сервис:

1. Выделяет текст поста.
2. **Либо** правая кнопка → «Найти размещения в МедиаПульс»,
   **либо** клик по иконке расширения → в окошке уже подставлен выделенный текст → «Найти».
3. В окошке — ход поиска, затем список найденного: **заголовки, раскрываются** в выдержку, источник,
   дату, связь с запросом и ссылку на пост — как карточки на сайте, только компактно.
4. Внизу — «Открыть подборку на сайте» (`/search/{id}`) и «Открыть МедиаПульс».

## Решения

| Вопрос | Решение |
|---|---|
| Браузер | Chrome MV3. Тот же пакет ставится в **Яндекс Браузер** (поддерживает расширения Chrome) — проверить в обоих |
| Установка | zip из релиза → «Загрузить распакованное» (режим разработчика). Права администратора ОС не нужны — это пункт ТЗ |
| Где искать | **Мои источники** (активные из каталога), **30 дней** по дате публикации, все доступные площадки. В окошке переключатель «Везде» и выбор 7 / 30 дней |
| Запуск | оба способа: контекстное меню по выделению + кнопка в окошке |
| Окошко закрывается при клике мимо | поиск идёт в **service worker**; `searchId`, текст и статус — в `chrome.storage.session`. Открыл окошко снова — видишь ход или результат. Готово → бейдж на иконке с числом найденного |
| Адрес сервера | по умолчанию из сборки (`VITE_API_URL=http://109.196.167.204:8080`), меняется на странице настроек расширения |
| CORS | не нужен: у расширения `host_permissions` на адрес сервера |

## Сделать

1. **Каркас** — внутри `frontend/` (переиспользуем `src/api/client.ts`, типы, `PlatformLogo`, `Icon`,
   тему): `frontend/extension/manifest.json`, `popup.html` + `src/extension/popup.tsx`,
   `src/extension/background.ts`, `options.html`. `vite.extension.config.ts` (несколько входов) →
   `npm run build:ext` → `frontend/dist-ext/` → `npm run zip:ext` → `dist-ext.zip`. Mantine dates и
   MSW в сборку расширения не тянуть (размер).
2. **manifest.json:** `manifest_version: 3`, `action.default_popup`, `background.service_worker`,
   `permissions: ["contextMenus", "storage", "activeTab", "scripting"]`,
   `host_permissions: ["http://109.196.167.204:8080/*"]` (+ `optional_host_permissions: ["<all_urls>"]`
   для смены адреса), иконки 16/32/48/128 из фавикона.
3. **Выделенный текст:** из контекстного меню — `info.selectionText`; в окошке —
   `chrome.scripting.executeScript({target: {tabId}, func: () => getSelection()?.toString()})`.
   Пусто — поле ввода «Вставьте или выделите текст поста». Меньше 3 символов — подсказка, как на сайте.
4. **Запуск поиска (background):**
   - `GET /api/v1/platforms` → площадки не `unavailable`;
   - `GET /api/v1/sources?limit=200` → `is_active` → `source_ids` (как форма на сайте);
   - `POST /api/v1/searches` `{query, period_from, period_to (30 дней по Красноярску), mode: "selected", platforms, source_ids}`;
   - опрос `GET /api/v1/searches/{id}` раз в 2 с до финального статуса (`chrome.alarms`, если
     service worker уснёт);
   - готово → бейдж `chrome.action.setBadgeText`, из контекстного меню — `chrome.action.openPopup()`
     (Chrome 127+; не сработало — остаётся бейдж).
5. **Окошко (≈ 400 × 560):**
   - вверху — текст запроса в 2 строки (раскрывается), период, режим;
   - идёт — стадия и прогресс (`stageText` из `features/search/status.ts`), «Остановить»;
   - результат — `GET /results?sort=relevance&limit=20`: строка = логотип площадки + **заголовок** +
     «Прямая / Косвенная / Спорно» + процент; клик раскрывает выдержку с подсветкой, источник, дату
     («Дата недоступна», если нет), объяснение, «Открыть пост ↗»;
   - пусто / частично / ошибка — те же тексты, что на сайте (`SearchOutcome`), коротко;
   - внизу всегда: «Открыть подборку на сайте ↗» и «Открыть МедиаПульс ↗»;
   - светлая / тёмная тема — по системе, стиль нового дизайна (Manrope, лайм).
6. **Настройки:** адрес сервера (проверка — `GET /health/ready`), режим и период по умолчанию.
7. **Бонус (P2):** на странице группы VK / OK / MAX — кнопка в окошке «Добавить страницу в источники»
   (`POST /sources/resolve` → `POST /sources`), переиспользовать логику `AddSource`.
8. README: раздел «Расширение»: установка в Chrome и Яндекс Браузер (со скриншотами), что умеет,
   ограничения.

## DoD
1. На чистом Chrome и в Яндекс Браузере: установить zip → выделить текст поста VK → ПКМ «Найти
   размещения» → через 1–3 мин (с кэшем B2-20 — сразу) в окошке список заголовков, раскрываются,
   ссылки ведут на посты; «Открыть подборку на сайте» открывает тот же поиск с тем же числом публикаций.
2. Закрыл окошко посреди поиска → открыл снова → видно ход / результат, поиск не потерян.
3. Сервер недоступен → в окошке «Нет связи с сервером», а не пустой экран.
4. `npm run typecheck && npm run build && npm run build:ext` зелёные; zip — в релизе / `docs/demo/`.
5. Короткая запись экрана сценария для презентации (UI-10).
