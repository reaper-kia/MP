# ML — день 2

Зона: `services/ml_service`, `eval/`. Критерии: сценарии 1–2 (готовность 3 + 3, UX 2 + 2), ценность,
обоснованность (модели, расходы), слайд «Качество».

Что выяснили сегодня: на ноуте модели работают (`qwen2.5:7b-instruct` + `bge-m3`, 100 % GPU), судья
успевает ~6–13 постов из 30 за вызов, бюджет иногда кончается («не успел в бюджет, 2 постов остались с
оценкой v1»). **Сервер для экспертов — 2 vCPU, 3.8 ГБ RAM, без GPU**: там сейчас `stub`, а на
эвристиках recall «темы» 24 %. Эксперты будут искать именно на сервере.
