# UI — презентация и визуальное ревью, день 2

Раздел 1 критериев (10 баллов) целиком про презентацию и показ, плюс «Ценность» (5),
«Пригодность» (2) и «Доп. идеи» (5) оцениваются по тому, **как мы их объясним**. Презентация — это
не пересказ функций, а ответ на «почему этому можно доверять и какую работу сервис берёт на себя».

**Правила.** На слайде — один тезис и одна картинка; термины без жаргона (не «gRPC», а «сервис
поиска»); цифры только проверенные, с подписью «на чём замерено». Палитра и шрифт — из нового
дизайна (Manrope, лаймовый акцент, тёплый светлый фон).

**DoD.** Презентация в общем доступе у команды; TL прогнал её с таймером (TL-20); все цифры сверены
с `docs/demo/metrics.md` и `eval/report_real.md`.
