## Сценарий 1 · Поиск по теме, событию или человеку

| Действия | Ожидаем | Чьё, если не так |
|---|---|---|
| В одно поле вводим «Безопасность дорожного движения в Красноярском крае» | Поле одно; отдельного экрана под тип запроса нет | FE |
| Ставим период (последние 7 дней) и режим «по источникам», запускаем | Поиск стартовал, видна стадия и прогресс | FE, B2 |
| Дожидаемся конца | Видно число публикаций, площадки, источники, выдержки | FE, B2 |
| Просматриваем подборку | Новости про *пожарную* безопасность не попали только из-за слова «безопасность» | ML |
| Повторяем по событию с уточнением (придумать до прогона пример с уточнением: что, где, когда) и по человеку («Иван Иванов, Курск») | Подборка про событие/человека, не про одноимённых | ML |
| Расплывчатый запрос («новости») | Система предлагает уточнить, а не выдаёт шум | ML, FE |

## Сценарий 5 · Пустая выдача и недоступный источник

| Действия | Ожидаем | Чьё |
|---|---|---|
| Запрос, по которому ничего нет | «Подходящих публикаций не найдено» — **не** сообщение об ошибке | FE |
| Источник закрыт / не найден / площадка недоступна (в проде — отключить токен VK или взять закрытую группу) | Статус `partial`; найденное сохранено; недоступные источники перечислены отдельно, причина понятна | B1, B2, FE |
| «Повторить» | Повторная попытка по недоступным источникам | B2, FE |

**Где гоняли.** Не на сервере — адреса стенда пока нет. Локально: `docker compose up -d --build` из
ветки `fe-day2` (main `cb7ab0d` + FE-13/14/10/16), фронт — http://localhost и dev-сервер Vite с прокси на
gateway. Без ключей: VK и MAX «не подключены» (нет `VK_SERVICE_TOKEN`, `MAX_BOT_TOKEN`), у OK нет поиска
«везде» (нет ключа Yandex Search API), ML «в упрощённом режиме». Каталог: `make seed` добавил 3 группы OK
(VK-строки отклонены без ключа) + 4 новостных сайта добавлены руками через `/sources?add=…` (путь
расширения FE-10). Браузер 1366×768, светлая и тёмная тема; **1920×1080 и проектор не
проверяли** — повторить на сервере.

Поиск по 7 источникам идёт ~52–53 с (4 запуска), то есть «обычно 1–3 минуты» под прогрессом честно.
