## Сценарий 1 · Поиск по теме, событию или человеку

| Действия | Ожидаем | Чьё, если не так |
|---|---|---|
| В одно поле вводим «Безопасность дорожного движения в Красноярском крае» | Поле одно; отдельного экрана под тип запроса нет | FE |
| Ставим период (последние 7 дней) и режим «по источникам», запускаем | Поиск стартовал, видна стадия и прогресс | FE, B2 |
| Дожидаемся конца | Видно число публикаций, площадки, источники, выдержки | FE, B2 |
| Просматриваем подборку | Новости про *пожарную* безопасность не попали только из-за слова «безопасность» | ML |
| Повторяем по событию с уточнением (придумать до прогона пример с уточнением: что, где, когда) и по человеку («Иван Иванов, Курск») | Подборка про событие/человека, не про одноимённых | ML |
| Расплывчатый запрос («новости») | Система предлагает уточнить, а не выдаёт шум | ML, FE |

## Сценарий 2 · Поиск по исходной новости

| Действия | Ожидаем | Чьё |
|---|---|---|
| Вставляем полный текст новости в то же поле | Запрос распознан как «текст новости» (в интерфейсе видно) | ML, FE |
| Источники: те, где лежат оригинал, сокращённая версия и похожая новость о другом событии | Оригинал и сокращённая найдены; похожая о другом событии — нет | ML |
| Одна новость в трёх группах | Три отдельные записи, `counts.total` = 3; в группировке видны все ссылки | B2, FE |

## Сценарий 3 · Период и источники

| Действия | Ожидаем | Чьё |
|---|---|---|
| Поиск по выбранным источникам, затем меняем период и состав источников | Новая подборка по новым условиям; параметры показанной подборки подписаны | FE, B2 |
| Запускаем «без ограничения списком» | Видно, что искали по площадкам целиком, а не по списку | FE |
| Материал без даты | Не помечен как «точно в периоде» (`date_status: unknown`) | B2, FE |
| Меняем запрос / запускаем повторно | Результаты разных поисков не смешались | FE |

## Сценарий 4 · Проверка подборки и выгрузка

| Действия | Ожидаем | Чьё |
|---|---|---|
| Открываем 3–5 ссылок | Ведут на конкретный пост; заголовок и выдержка совпадают с текстом | B1, B2 |
| Исключаем лишнее | Счётчики пересчитались | B2, FE |
| Выгружаем XLSX и открываем в Excel/LibreOffice | Те же записи; есть № записи, запрос, период, количество; ссылки открываются | B2 |
| Повторно запускаем поиск, который находит тот же пост | Новая запись не появилась, `total` не вырос | B2 |

## Сценарий 5 · Пустая выдача и недоступный источник

| Действия | Ожидаем | Чьё |
|---|---|---|
| Запрос, по которому ничего нет | «Подходящих публикаций не найдено» — **не** сообщение об ошибке | FE |
| Источник закрыт / не найден / площадка недоступна (в проде — отключить токен VK или взять закрытую группу) | Статус `partial`; найденное сохранено; недоступные источники перечислены отдельно, причина понятна | B1, B2, FE |
| «Повторить» | Повторная попытка по недоступным источникам | B2, FE |
