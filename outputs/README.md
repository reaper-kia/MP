## Где смотреть поля, типы и API

| Кому | Справочник (читать) | Первоисточник (править только через TL) |
|---|---|---|
| FE, UI, TL | [`docs/API.md`](../API.md) — все HTTP-ручки, параметры, коды, схемы с типами; [`docs/api-types.ts`](../api-types.ts) — TS-типы | `contracts/http/openapi.yaml` |
| B1, B2, ML, TL | [`docs/GRPC.md`](../GRPC.md) — все RPC и сообщения с типами и комментариями | `contracts/*/v1/*.proto` |

Справочники генерируются из контрактов (`python3 scripts/gen_api_docs.py`, `python3 scripts/gen_grpc_docs.py`) —
руками не правятся. В каждой задаче нужные ручки/сообщения и поля выписаны прямо в тексте.

## Как читать задачу

```
### B2-05 · P0 · к H+10 · зависит от: B2-01, B1-02
Цель — зачем (и какой критерий оценки это закрывает)
Сделать — по пунктам
DoD — проверяемые условия «готово»
```

- **P0** — без этого не проходит сценарий ТЗ. Делается первым, нельзя пропускать.
- **P1** — даёт баллы (доп. возможности, UX), делается после P0 своей вехи.
- **P2** — если осталось время до H+38.
- Взял задачу → пишешь в чат «беру B2-05». Сделал → `make check` зелёный, PR, галочка `[x]` в файле.
- Блокер больше 30 минут → сразу в чат TL. Не сидим молча.

## Общий DoD для любой задачи

1. Работает в `make up` (Docker), а не только локально.
2. `make fmt && make check` зелёные (ruff, mypy --strict, pytest).
3. Есть хотя бы один тест на основную логику (хэндлеры — на фейках, как в шаблоне).
4. Ошибки — через `ERROR_CODES`, а не `try/except` в servicer/роутере.
5. Логи с `request_id`, без секретов и без полных текстов постов на уровне INFO.

## Критический путь

```
TL-01 сервисы ─▶ TL-02 контракты ─┬─▶ B1-02 стаб collector ─▶ B1-03 VK ───────────┐
                                  ├─▶ ML-01 стаб ml ─▶ ML-04 v1 ─▶ ML-05/06 v2 ───┤
                                  ├─▶ B2-01 домен ─▶ B2-04 пайплайн ─▶ B2-05/07/08 ┼─▶ H+12 MVP-1
                                  └─▶ FE-01/02 моки ─▶ FE-03..07 ──────────────────┘
B1-01 spike OK/MAX (параллельно с H0) ─▶ B1-04 OK, B1-05 MAX, B1-06 global ─▶ H+24 MVP-2
```

Правило стабов: **к H+3 каждый сервис отвечает по контракту** (пусть и фейковыми данными, явно
помеченными) — чтобы соседи интегрировались, не дожидаясь настоящей логики.
